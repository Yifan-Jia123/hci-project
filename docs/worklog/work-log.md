# 成员工作记录

记录各成员已完成的工作，按日期倒序排列。

## 填写方式

每完成一项工作，在下方「记录」表追加一行。

| 字段 | 说明 |
|---|---|
| 日期 | 完成日期，格式 `YYYY-MM-DD` |
| 成员 | 执行人 |
| 分支 | 执行该工作时所在的分支 |
| 完成内容 | 一句话说明做了什么，包含关键对象与结果 |
| 提交 | 提交号前 7 位；未产生提交的工作填写「无」 |

同一工作涉及多条分支时，分行记录。工作内容涉及方案取舍的，在完成内容一栏注明被放弃的方案。
