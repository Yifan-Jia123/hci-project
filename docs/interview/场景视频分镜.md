# 场景视频分镜｜两小时内完成通路作业

**片长：约 3 分 15 秒。**全片只有 A、B 两人入镜。A 负责把作业要求写在白板上并操作电脑，B 带着课堂资料和草图一起查证。作业要求：画出从指定起点到柠檬烯的通路，标出关键反应的候选酶和信息依据，在截止前提交。屏幕角落的倒计时贯穿故事，最后由“已提交”收尾。

**分工**：成员1，2，3各自认领

画面发生比较大的变化时生成一张图片，或者直接按照我们表格里的部分，每部分一张图也行。

| 时间 | 画面与动作 | 对白／声音 | 功能与画面重点 |
|---|---|---|---|
| **0:00–0:13｜任务压过来** | 手机弹出“距离作业截止还有 2 小时”。A 在白板写“起点 → 柠檬烯”，下面列出“通路、关键酶、依据”。B 翻出一张只画了部分结构的课堂草图。 | A：“两小时后要交，路线和酶怎么补？” | 用白板和倒计时一次交代目标与时限。 |
| **0:13–0:33｜旧方法卡住** | A 在常用数据库里切换多个页面，复制名称、逐条查反应，再回到白板，箭头仍断着。画面只需几个短切：页面跳转、表格比对、便签贴错又撕下。B 看着时间变少。 | A：“查到一个化合物，又得重新找它连着哪一步。”B：“这样一条条拼太慢了。” | 竞品只呈现实际操作步骤；突出“信息分散、拼通路耗时”。 |
| **0:33–0:38｜发现网站** | B 从课程群打开项目网站，把电脑转向 A。A 指着白板上断开的起点和终点。 | B：“试试这个网站。” | 让网站的出现回应刚才卡住的任务。（电脑上面出现我们的项目名字） |
| **0:38–0:42｜空镜提问一** | 空白白板上只剩“起点 → ？ → 柠檬烯”，镜头缓慢推近断开的箭头；A、B 不入镜。 | A 画外音：“整条通路到底怎么连起来？” | 以白板问题切入图谱，保留环境声，不用黑屏字卡。 |
| **0:42–1:10｜功能一：图谱** | A 输入已确认可检索的起点与终点；录屏展示通路结果、节点与连线。B 点开其中一条连接看反应和关联酶；A 依照结果把白板上第一段箭头接上。 | B：“先看全貌，再决定哪一步要细查。” | 实拍“看屏幕—讨论—补白板”与两处关键录屏交替。 |
| **1:10–1:14｜功能关键词一** | 定格在图谱结果，三个词依次浮现，再回到白板已接上的箭头。 | 音乐短促上扬。 | **通路图谱｜节点关系｜反应信息**。 |
| **1:14–1:18｜空镜提问二** | 空镜扫过桌上的结构草图和蛋白序列纸，纸上名称栏空着。 | B 画外音：“只记得结构和序列，还能找到它们吗？” | 从“看见通路”自然转到“补齐未知条目”。 |
| **1:18–1:46｜功能二：多种搜索方式** | B 在结构画板画出草图中的化合物，查看匹配条目，给白板补上名称。A 从课堂资料中找到一段蛋白序列，打开 BLAST，粘贴序列并查看相似酶结果，把一个候选酶记在待核对栏。 | A：“有结构就按结构找；有序列还能找相似的酶。” | 两组 6–8 秒操作特写展示输入与结果。BLAST 命中只作为候选线索。 |
| **1:46–1:49｜功能关键词二** | 画板匹配条目与 BLAST 命中结果分屏，关键词叠加在各自画面下方。 | 两声轻提示音。 | **结构画板｜BLAST｜多种搜索方式**。 |
| **1:49–1:53｜空镜提问三** | 白板已补上化合物与候选酶，但几条彩色路线同时通往终点；镜头停在未圈定的分叉处。 | A 画外音：“路线有好几条，怎么找出我们要讲的那条？” | 分叉成为下一段追踪操作的动机。 |
| **1:53–2:18｜功能三：追踪主线** | B 对照课堂草图指向要讲的一条。A 进入追踪模式，从起点逐个选择相连化合物直到终点，得到对应路径；B 在白板上用彩笔沿所选路线连点成线。 | B：“就是这条，沿着它走一遍。” | 展示自主逐点选择和最终路径。倒计时可跳切到“还剩 20 分钟”。 |
| **2:18–2:21｜功能关键词三** | 图谱中的选中路线与白板彩笔主线做一次匹配剪辑，关键词在主线旁出现。 | 音乐节奏稍加快。 | **逐点追踪｜自定路径｜锁定主线**。 |
| **2:21–2:25｜空镜提问四** | 镜头掠过白板上的主线，停在一处仍空着的“酶／依据”栏。 | B 画外音：“这一步的酶和依据，去哪儿核对？” | 把追踪得到的路线接到证据核对。 |
| **2:25–2:45｜功能四：数据库助手** | A 在当前页面打开数据库助手提问，顺着回答中的条目链接查看酶、反应或来源信息。B 将核对过的候选酶和依据写到白板上，并在作业文档中补齐。 | A：“先用助手定位，再回条目确认。” | 保留提问、引用入口和核对动作；助手回答不是最终依据。 |
| **2:45–2:48｜功能关键词四** | 助手的引用入口切到数据库条目，再切到作业文档中补全的依据栏。 | 提示音落在填写完成时。 | **数据库助手｜信息定位｜条目核对**。 |
| **2:48–3:00｜完成并提交** | 回到开头同一白板机位：起点、终点、主线路径、关键酶与依据已齐。两人快速检查作业文档，A 点击课程平台“提交”；画面清楚出现“提交成功”和截止前时间。B 松一口气。 | B：“交上了。”音乐在提交成功后落下。两个人应该是很兴奋的 | 白板前后对比承接四项功能的成果；以实际提交状态作为故事终点。 |
| **3:00–3:15｜项目概括** | 两人故事结束。用图谱、结构画板与 BLAST、逐点追踪、数据库助手的短录屏串成四连镜头，最后停在项目名称。 | 旁白：“通路图谱展示全貌，结构和序列搜索补齐线索，逐点追踪锁定主线，数据库助手帮助核对依据。让分散信息连成能讲清的作业。” | 每个功能出一个简短关键词字幕；片尾不再增加新剧情。 |
